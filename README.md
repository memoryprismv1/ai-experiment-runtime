# AI Experiment Runtime

An independent, general-purpose Python environment for controlled AI experiments. Skills are one kind of test subject; the runtime is designed to extend to models, agents, workflows, datasets, software, and multimodal systems.

The runtime uses Q-Batch of Evidence as a separate evidence and verification layer. It does not depend on or integrate with AEL.

Initial implementation is being developed in a feature branch. See the first implementation PR for the experiment format, Python runner, Q-Batch integration, and CI verification.
